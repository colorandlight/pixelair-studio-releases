# PixelAir Studio releases

Public **macOS downloads** for PixelAir Studio by [Color+Light](https://colorandlight.art): write, preview and run animations on Fluora lamps.

This repository does **not** contain application source. It exists so anyone can download a notarized build without access to the private codebase. It also hosts `appcast.xml`, the Sparkle feed the app's **Check for Updates…** reads.

## Install

1. Open the latest [Release](https://github.com/colorandlight/pixelair-studio-releases/releases).
2. Download `PixelAir-Studio-x.y.z.dmg`.
3. Open the disk image and drag **PixelAir Studio** into Applications.

Requires macOS 26 or later on Apple silicon. The app is Developer ID signed and notarized.

## Updating

**PixelAir Studio → Check for Updates…** in the app. It also checks in the background, but never installs without asking.
